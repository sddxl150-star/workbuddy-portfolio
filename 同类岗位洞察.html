MiniMax

上海 · 北京 · 深圳｜估值超 2500 亿港元"大模型第一股"

医疗专属岗：无。 公开在招以 AGI 算法、多模态、Agent 研发工程师、大模型产品经理、大模型数据运营、海外创意策划为主，无医疗垂直团队。

可面方向：Agent 研发 / 大模型产品 / 数据运营 / 海外创意 —— 与主投岗"生态 + 海外"高度同构，强烈建议面。

投递：官网招聘 / 脉脉 / BOSS 直聘

通用AI

Kimi（月之暗面）

北京 · 上海 · 深圳｜Kimi K3 万亿参数

医疗专属岗：无。 在招集中在算法与工程（推理框架、多模态）、用户产品经理、开发者生态、增长运营、API 商业化、大模型数据运营。

可面方向：开发者生态 / 增长运营 / API 商业化 —— 典型的 Agent 平台生态运营岗，建议面。

投递：careers.kimi.com / BOSS 直聘

有医疗团队

DeepSeek

北京 · 杭州｜明确组建医疗方向团队

医疗岗：有，且成体系。 医疗数据百晓生、AI 产品 / 数据百晓生（医疗方向）、全科开发工程师（医疗方向）、医疗 AI 算法、医学 NLP 研究员、临床数据科学家、AI 医疗产品经理、医学知识图谱工程师。

匹配度低：清一色 技术研发 / 医学专业 要求（临床背景 + Python + Prompt），与 To B 生态合作 / 运营不匹配；且 DeepSeek 偏研究型，商业化生态岗极少。仅作关注，不优先。

投递：career@deepseek.com / 官网
